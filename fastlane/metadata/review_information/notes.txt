ENGLISH

1. No sign-in and no demo account. On first launch choose an available name (3–20 lowercase letters, digits or hyphens). The identity is a key pair generated on the device; no email or password.

2. Receiving: each device has one address, https://yourname.stolnk.com (no paths). Open Received with the bottom-left button on the Drive home screen, or Me → address. Open that address in Safari on any device and upload a file; it is encrypted in the browser and arrives in Received. Keep the app in the foreground.

3. Sending: tap ⋯ next to a file → Create download link. The https://yourname.stolnk.com/~code link downloads in any browser. Download links are not end-to-end encrypted; the form says so.

4. Pricing: free download with two optional in-app purchases, both sold only through StoreKit inside the app (Me → Membership); there is no login, license key, redemption field or external purchase link. The website only describes them and links to the App Store.
   (a) Stolnk Membership: auto-renewing subscription, com.nbtxy.filego.member.yearly, $1.99/year, group "Stolnk Membership".
   (b) Stolnk Lifetime: one-time non-consumable, com.nbtxy.filego.member.lifetime, $9.99, no renewal.
   Non-members can receive files but cannot create download links and use free limits (2 GB files, 3 GB/month relay, no passwords). Members can create links, keep their subdomain permanently (editable any time), and get 20 GB files, 300 GB/month relay and password-protected links. A non-member's custom subdomain lasts 7 days, then the address stops working and the name is released; the user must set a new subdomain. Previous $1.99 paid-download buyers get one year of membership free; the previous $14.99 lifetime product is no longer sold but is still honoured for its buyers. Terms, both prices, Restore Purchases, Manage Subscription, Terms of Use (Apple standard EULA) and Privacy Policy are on the membership screen. Stolnk is iPhone-only; the former Mac and Windows apps are discontinued and nothing is sold outside the App Store.
   Sandbox: use TestFlight or Settings → App Store → Sandbox Account. Buy either option from Me → Membership or Create download link. A sandbox yearly subscription renews in about 1 hour; the lifetime purchase never renews. After expiry links pause and the subdomain returns to the 7-day rule. Restore Purchases syncs both products; with no purchase, Create download link shows the membership screen.

5. Account deletion: Me → Delete account. It deletes the name, address, links and all server-side data for the device immediately.

6. HTML and Markdown previews are local file previews, not a general browser. Both load remote images automatically and ask before full-page external navigation. AI-generated HTML renders as a page and Markdown is typeset.

7. Local file tools & clipboard: long-press for multi-select, local ZIP/TAR/GZ compression & extraction, optional password-protected hidden vault (Library/Application Support/StolnkVault, revealed via Search), Save to Photos (NSPhotoLibraryAddUsageDescription), and Shared Clipboard (Me → Shared Clipboard, synced in real time with https://yourname.stolnk.com/clip).

8. No ads, ATT prompt, analytics SDK or third-party tracking. Backend: https://stolnk.com on Cloudflare.

9. Encryption: only Apple CryptoKit standard algorithms (P-256, AES-GCM, HKDF, SHA-256); export exemption.

中文

1. 无需登录或演示账号；首次启动选一个可用名字，身份是设备生成的密钥对。
2. 接收：每台设备一个地址 https://yourname.stolnk.com；从首页左下角或「我的」进入「收到的文件」，任意浏览器上传。
3. 发送：文件右侧 ⋯ → 创建下载链接（非端到端加密，表单已说明）。
4. 定价：免费下载，仅通过 App 内 StoreKit（我的 → 会员）提供两项可选内购：年订阅 com.nbtxy.filego.member.yearly ($1.99/年) 与终身版 com.nbtxy.filego.member.lifetime ($9.99 一次性)。非会员限额 2 GB/文件、3 GB/月中转，子域名 7 天失效；会员 20 GB/文件、300 GB/月中转、永久子域名、下载链接与密码保护。旧付费用户赠一年会员。仅 iPhone 版。沙盒支持购买与恢复购买。
5. 删除账号：「我的 → 删除账号」。
6. HTML/Markdown 为本地预览，自动加载远程图片，外链跳转先询问。
7. 本地功能：长按多选、ZIP/TAR/GZ 压缩解压、带密码的本地私有隐藏目录（搜索输入密码查看，选目录取消隐藏）、图片视频保存到相册（仅添加权限）。
8. 无广告/ATT/统计 SDK；仅用 CryptoKit 标准加密（P-256/AES-GCM/HKDF/SHA-256）。
